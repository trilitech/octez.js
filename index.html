    What makes octez.js so amazing?

    Get Started

    Easy To Use

    octez.js's abstractions are simple to understand and use. Working with Tezos contracts feels like working with JavaScript objects.

    Catch Errors Early

    octez.js uses TypeScript to extend JavaScript so that you can catch errors earlier.

    Portable

    Perfect for any JavaScript project on the front-end, back-end or command line with minimal dependencies.

    Well Supported

    octez.js has a well-documented API, runs continuous integration tests against the Tezos Node and a set of Beacon wallets.
